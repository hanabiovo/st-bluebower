# Bluebower (园丁鸟)

一个轻量、流畅、**直接增强 SillyTavern 原生界面**的预设条目（Prompt）与正则条目（Regex）分组折叠插件。

## 核心特性

- **原生界面直接增强**：不另开独立大弹窗，直接在酒馆原生的 **预设条目列表** 与 **正则脚本列表** 中原地分组折叠，完整保留酒馆自带的编辑、检视、Token 计算、导入导出等全部操作。
- **兼容柏宝箱（ST-BaiBai-Tools）生态**：
  - 自动读取并迁移预设中的 `extensions.baibaiToolkit.presetPromptGroups` 分组数据。
  - 默认开启**非破坏性双向同步**（可在设置中关闭），修改基础分组后同步写回柏宝箱格式，两个插件间可平滑切换。
- **互斥单选组**：可将任意分组设为“互斥”，开启组内某一项时自动关闭同组其他项（适合多套状态栏或思维链切换）。
- **常用星标置顶 & 个人备注**：把高频开关条目星标置顶到预设列表最上方，并支持给分组或条目添加个人备注。
- **快速筛选与防误触锁序**：支持关键词搜索、`已启用` / `★` 过滤，以及默认锁定预设拖拽排序，防止误触打乱顺序。
- **分组 Token 合计 & 正则作用范围角标**：直接汇总原生条目 Token 数显示在分组标题栏；正则条目自动标注 `仅渲染` / `仅发送` / `双向` 角标。

## 安装方式

在 SillyTavern 扩展管理中通过仓库地址安装：

```text
https://github.com/hanabiovo/st-bluebower.git
```

安装并刷新后，直接打开酒馆的 **AI 响应配置（预设条目列表）** 或 **正则扩展面板** 即可看到园丁鸟工具栏与分组折叠效果。

# Bluebower (园丁鸟)

一个轻量、流畅、**直接增强 SillyTavern 原生界面**的预设条目（Prompt）与正则条目（Regex）分组折叠插件。

## 核心特性

- **原生界面直接增强**：不另开独立大弹窗，直接在酒馆原生的 **预设条目列表** 与 **正则脚本列表** 中原地分组折叠，完整保留酒馆自带的编辑、检视、导入导出等全部操作，并默认收纳预设页参数杂项（`预设设置`）。
- **完整兼容柏宝箱（ST-BaiBai-Tools）生态**：
  - 自动读取并迁移预设中的提示词分组（`baibaiToolkit.presetPromptGroups`）、预设正则分组（`baibaiToolkit.regexGroups`）以及本地全局/角色正则分组。
  - 默认开启**非破坏性双向同步**（可在扩展设置中关闭或一键恢复为柏宝箱版分组），两个插件间可平滑切换。
- **纯预设词条 Token 统计 & 正则作用范围角标**：顶部栏与各分组自动剔除聊天记录、世界书、角色卡等上下文槽位，精准统计纯预设提示词 Token；正则条目自动标注 `仅渲染` / `仅发送` / `双向` 角标，未分组正则自动归入默认折叠的「默认」组。
- **互斥单选组**：可将任意分组设为“互斥”，开启组内某一项时自动关闭同组其他项（适合多套状态栏或思维链切换）。
- **常用星标置顶 & 个人备注**：把高频开关条目星标置顶到预设列表最上方，并支持给分组或条目添加个人备注。
- **顺手的多选归组与防误触锁序**：点击条目即可高亮多选（支持吸顶操作栏与选后直接新建分组移入），默认折叠隐藏危险移除按钮并锁定预设顺序，移动端与桌面端均零延迟响应。

## 安装方式

在 SillyTavern 扩展管理中通过仓库地址安装：

```text
https://github.com/hanabiovo/st-bluebower.git
```

安装并刷新后，直接打开酒馆的 **AI 响应配置（预设条目列表）** 或 **正则扩展面板** 即可看到园丁鸟工具栏与分组折叠效果。

# Bluebower (园丁鸟)

一个轻量、流畅、适配 SillyTavern 原生主题的**预设条目（Prompt）与正则条目（Regex）分组管理插件**。

## 核心特性

- **零外部依赖**：纯原生 JS + CSS 实现，按需懒渲染，折叠分组不生成多余 DOM，不增加启动与切换负担。
- **兼容柏宝箱（ST-BaiBai-Tools）生态**：
  - 自动读取并迁移预设中的 `extensions.baibaiToolkit.presetPromptGroups` 分组数据。
  - 默认开启**非破坏性双向同步**（可在设置中关闭），修改基础分组后同步写回柏宝箱格式，两个插件间可平滑切换。
- **互斥单选组**：可将任意分组设为“互斥”，开启组内某一项时自动关闭同组其他项（适合多套状态栏或思维链切换）。
- **常用星标置顶 & 个人备注**：把高频开关条目星标置顶到最上方，并支持给分组或条目添加个人备注。
- **快速筛选与防误触锁序**：支持关键词搜索、`仅已启用` / `★ 星标` 过滤，以及默认锁定预设发送顺序（`prompt_order`），防止误拖拽。
- **分组 Token 估算 & 正则作用范围角标**：异步缓存估算各组已启用条目的 Token 占用；正则列表直接标注来源（`预设` / `角色` / `全局`）与作用范围（`仅渲染` / `仅发送` / `双向`）。

## 安装方式

在 SillyTavern 扩展管理中通过仓库地址安装：

```text
https://github.com/hanabiovo/st-bluebower.git
```

安装后可在以下位置打开园丁鸟分组面板：
1. 扩展菜单（魔法棒）中的 **园丁鸟分组 (Bluebower)**
2. OpenAI 预设条目管理器顶部的 **🐦 分组视图** 按钮
3. 正则扩展面板顶部的 **🐦 正则分组** 按钮
